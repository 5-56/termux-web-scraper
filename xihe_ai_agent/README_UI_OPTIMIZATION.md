# 羲和AI代理系统 - 界面优化版

## 🎨 界面优化概述

羲和AI代理系统现在拥有了全新的、简洁明了的用户界面，专注于AI交互体验，并支持多种AI模型提供商。

## ✨ 主要界面特性

### 1. **简洁的主界面**
- **聊天式交互**: 主界面采用聊天式设计，用户可以像与真人对话一样与AI交互
- **实时响应**: 支持实时消息显示和打字指示器
- **快速操作**: 提供常用命令的快速按钮
- **响应式设计**: 完美适配桌面和移动设备

### 2. **可折叠侧边栏**
- **聊天历史**: 显示所有历史对话记录
- **新对话**: 一键开始新的对话会话
- **功能导航**: 快速访问各个功能模块
- **移动端适配**: 在移动设备上可折叠隐藏

### 3. **多模型支持**
- **6大提供商**: 支持Google、DeepSeek、Kimi、智谱AI、OpenRouter、OpenAI
- **模型选择**: 每个提供商提供多个模型选择
- **配置管理**: 支持API Key、Base URL等配置
- **连接测试**: 实时测试模型连接状态

## 🔄 实时通信

### WebSocket事件
- `connect`: 客户端连接
- `disconnect`: 客户端断开
- `ai_command`: AI命令执行
- `ai_response`: AI响应
- `ai_typing`: 打字指示
- `update_model_config`: 模型配置更新

### 消息格式
```javascript
// AI命令
{
  "command": "刷抖音视频10个",
  "chat_id": "chat_1234567890"
}

// AI响应
{
  "message": "正在执行刷抖音视频任务...",
  "status": "completed",
  "success": true
}
```

## 🚀 快速开始

### 1. 启动Web服务器
```bash
cd xihe_ai_agent/web_server
python app.py
```

### 2. 访问界面
打开浏览器访问: `http://localhost:5000`

### 3. 配置AI模型
1. 点击右上角"模型设置"
2. 选择提供商和模型
3. 输入API Key
4. 保存配置

### 4. 开始对话
1. 在输入框中输入指令
2. 按Enter发送
3. 查看AI响应和执行结果
